# Plans

Written by [`/planx`](../../.claude/commands/planx.md), executed by [`/feature`](../../.claude/commands/feature.md).

- Path: `docs/plans/<YYYY>/<MM>/<DD>/<1NN>-<slug>/` — `1NN` starts at `101` per day.
- Files: `overview.md` + one `<NN>-<aspect>.md` per slice + `status.yml` (the only tracker).
- A plan dir maps to a GitHub milestone or epic; each slice maps to one issue and one PR.
